## Legend

| Column | Description |
|---|---|

| **Syl** | Syllable count |
| **Meaning** | English gloss |
| **Cat** | Primary part of speech (N=Noun, V=Verb, A=Adjective, N+V=dual, N→A=noun-derived adjective) |

| **Verb** | Tone-marked verb form |

| **Adverb** | Adverb form (Verb+`-s` or 3+ syl tone pattern) |
| **共識** | Community-consensus default colour prefix |

### Tone Notation

- `j` = High (H) tone marker on the vowel nucleus
- `v` = Low (L) tone marker on the vowel nucleus
- 1-syllable words: all forms **toneless** (flat mid-tone)
- 2-syllable words: Noun H→L, Verb L→H, Adjective = Noun+`-s`, Adverb = Verb+`-s`
- 3+ syllable words: Last-3 domain patterns (no `-s`); Adjective/Adverb use distinct tone patterns

### Orthographic Conventions

- Diphthong ending in `i` + `j`: the `i` is dropped (`soi`+`j`→`soj`, `koi`+`j`→`koj`)
