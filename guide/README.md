# Kilor Usage Guide

Practical guides for using Kilor expressively. Unlike `rules/` (which specifies *what is*), the `guide/` directory covers *how to use* — examples, style, rhetoric, and artistic patterns.

**Last updated:** 2026-08-07
**Version:** 1.2.0

---

## Files

| File | Topic |
|---|---|
| `emotional-register-usage.md` | Using colour emotional particles for rhetorical effect (反諷, 輕描淡寫, 重彩). Expanded examples, artistic layering techniques. |
| `colour-prefix-poetics.md` | The fossil-colour device: poets deliberately resurrect the colour prefix's etymological hue (double-voicing, the `a-` vs `awin` renewal tension). |
| `phonesthemes.md` | Recurring sub-morphemic sound sequences and their loose semantic associations. Informal etymological observations that inform word-creation intuition (non-normative). |
| `phonology-texture.md` | Aesthetic & emotional texture of every Kilor phoneme. Describes what each sound feels like, what tone/word type it suits (aggressive, smooth, heavy, etc.), and provides design principles for word creation. Reference for developers designing new roots, compounds, or poetic lines. |

## Style

Guide files may re-explain concepts for pedagogical clarity — the Single Source of Truth constraint does **not** apply. Redundancy with `rules/` is intentional when it aids learning.
