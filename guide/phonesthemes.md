# Kilor Phonestheme Patterns

**Last updated:** 2026-08-05
**Status:** Observation (informal, non-normative)

> This document records recurring sub-morphemic patterns in Kilor — phoneme
> sequences that appear across semantically related words but may not be fully
> decomposable into independent roots. These are **not** grammatical rules.
> They are etymological observations that may inform word creation intuition.

---

## What Is a Phonestheme?

A **phonestheme** is a recurring sound sequence that carries a loose semantic
association across multiple words, without being a fully independent morpheme.
Unlike a productive root (which can stand alone), a phonestheme only exists
embedded within larger forms.

| Language | Example | Meaning |
|:---|:---|:---|
| English | `gl-` in *glow, gleam, glitter, glare* | light / vision |
| English | `sn-` in *sniff, sneeze, snore, snort* | nose / breathing |
| Chinese | `氵` in 江, 河, 海, 洋, 湖, 泊 | water-related |
| Kilor | `li` in *lira, shili, wonli, liwat* | water-related |

Kilor phonesthemes sit between two categories:
- **Productive compound roots** (e.g. `fos` "ice" → *foshu, foske, fosgilan*) — these have their own DB entries and participate in the compounding system
- **Sub-morphemic patterns** (e.g. `li-` across *shili, wonli, liwat*) — these are historical echoes, not productive building blocks

## Observed Patterns

### WATER — `li`, `lira` (root), `won`

| Form | Gloss | Type |
|:---|:---|:---|
| `lira` | water / to water / wet | **root** (standalone) |
| `lirahup` | waterfall | compound (lira + hup) |
| `shili` | river | **root** (not decomposable) |
| `wonli` | sea / inland sea | **root** (not decomposable) |
| `wonir` | ocean / vast | **root** (not decomposable) |
| `liwat` | lake | **root** (not decomposable) |
| `liforli` | flood / to flood | **root** (not decomposable) |
| `blusa` | wave | **root** (not decomposable) |

**Observation:** `lira` is the productive water root and forms transparent
compounds (*lirahup* = waterfall). The phonetic kernel `li` also appears in
words classified as roots (*shili, wonli, liwat, liforli*) — these are
historically derived but no longer transparently decomposable in modern Kilor.
The initial `wo-` in *wonli, wonir* may itself be a phonestheme for "vastness"
or "large body."

**Cross-linguistic parallel:** Chinese 氵(水) radical — historically meaningful,
not productively used in modern word formation.

### ICE / COLD — `fos` (root)

| Form | Gloss | Type |
|:---|:---|:---|
| `fos` | ice / to freeze / frozen | **root** (standalone) |
| `foske` | frost | compound (fos + ke?) |
| `foshu` | blizzard | compound (fos + hu) |
| `fosgilan` | glacier / iceberg | compound (fos + gilan) |
| `fosli` | snow | compound (fos + lira) |
| `foskaera` | frozen soil | compound (fos + kaera) |
| `fosblon` | avalanche | compound (fos + blon) |

**Observation:** `fos` is a fully productive root — every word in this family
is a transparent compound. This contrasts with the water family, where `li-`
appears in opaque roots. The difference reflects a design choice: `fos` was
given full root status; `li` was not (except within `lira`).

### SKY / CELESTIAL — `auron` (root)

| Form | Gloss | Type |
|:---|:---|:---|
| `auron` | sky | **root** |
| `auronte` | dome / canopy | compound (auron + tek?) |
| `aurok` | cosmic / space | compound (auron + rok) |
| `auronius` | sky-like | suffix-derived (auron + -ius) |
| `auroneus` | of the sky / sky-born | suffix-derived (auron + -eus) |
| `austar` | dusk sky | compound (aus + tar) |

**Observation:** Fully productive root family. The derived forms use productive
suffixes (`-ius`, `-eus`). *austar* and *austarius* share `aus-` as a reduced
form of `auron`.

### MOUNTAIN — `gilan` (root)

| Form | Gloss | Type |
|:---|:---|:---|
| `gilan` | mountain | **root** |
| `foragilan` | volcano | compound (fora + gilan) |
| `fosgilan` | glacier / iceberg | compound (fos + gilan) |
| `gilan fora` | wildfire on mountain | multi-word compound |

**Observation:** Fully productive root. Participates in both mono-word and
multi-word compounding. Head-final semantics: `foragilan` = "fire-type mountain"
(volcano); `gilan fora` = "mountain fire" (wildfire).

### TIME / DAY — `roi` (bound), `tar`/`tlar` (bound), `saka` (bound)

| Form | Gloss | Note |
|:---|:---|:---|
| `piroi` | yesterday | pi- (before) + roi (day) |
| `paroi` | tomorrow | pa- (after) + roi (day) |
| `imaroi` | today | ima (current) + roi (day) |
| `pimaroi` | day before yesterday | pima (earlier) + roi |
| `pamaroi` | day after tomorrow | pama (later) + roi |
| `taroi` | week | tar (period?) + roi |
| `gauroi` | ten-day period | gau (10) + roi |

| `gustar` | summer | gus (hot) + tar |
| `fossar` | winter | fos (ice) + tar |
| `austar` | dusk sky | aus (sky) + tar |
| `apar` | spring | apa (?) + tar? |
| `choumar` | autumn | choum (?) + tar? |

| `esaka` | always | esa (all) + saka (time?) |
| `slosaka` | sometimes | slote (some) + saka |
| `nasaka` | never | na (not) + saka |

**Observation:** `roi` consistently means "day/sun-cycle" and `tar`/`tlar`
consistently means "season/period." `saka` means "frequency/time-interval."
None of these have standalone root entries in the DB — they are **bound
morphemes** that only exist in compounds. The words built with them are
classified as compounds in the DB (since their other components exist as
roots — `pi-`, `pa-`, `ima`, `gus`, `fos`, etc.), but `roi`, `tar`, and
`saka` themselves are sub-root elements.

**Cross-linguistic parallel:** English *-day* in *yesterday, today, tomorrow* —
a bound morpheme that never appears alone but is clearly meaningful.

## Design Implications

### For word creation

- **When creating a new word in an established phonestheme family**, prefer
  using the **productive root** rather than the sub-morphemic echo. For a new
  water concept, build from `lira` (*lira + X*), not from bare `li-`.
- **Sub-morphemic patterns** are historical artifacts — they may inspire new
  root creation but should not be treated as productive affixes.

### For database classification

- Words containing sub-morphemic patterns (*shili, wonli*) are correctly
  classified as **roots**, not compounds — their components are not
  decomposable into independent DB entries.
- Words built from productive roots (*foshu, foragilan*) are correctly
  classified as **compounds**.

### For potential future development

If Kilor develops a **historical linguistics** layer (a fictional language
history), these phonestheme patterns become evidence for reconstructing
earlier stages of the language — much as English `gl-` words trace back to
Proto-Germanic roots.
