# Kilor Phonology Texture Guide

**Module:** Aesthetic & emotional texture reference for the Kilor phoneme inventory
**Last updated:** 2026-08-06
**Version:** 1.0.0
**Spec reference:** `rules/0-foundation/phonology.md`

> This guide describes the **aesthetic texture** of every Kilor phoneme — what each sound *feels like*, what emotional tone it evokes, and what kind of words it suits. Use this as a creative reference when designing new roots, compounds, or poetic lines.
>
> Unlike `rules/0-foundation/phonology.md` (which specifies *what is*), this guide describes *how it feels*. Redundancy with the spec is intentional for creative clarity.

---

## I. How to Use This Guide

Each phoneme entry includes:

| Field | Description |
|:---|:---|
| **Texture** | Subjective description of the sound's aesthetic character |
| **Emotion** | What emotional register the sound naturally evokes |
| **Tone type** | Aggressive / smooth / sharp / gentle / heavy / light / dark / bright / soft / crisp |
| **Suited for** | Types of words where this sound works best (nouns, verbs, particles, poetry, etc.) |
| **Kilor example** | Real DB word demonstrating the sound in context |

**Design principle:** Mix sounds from different texture categories to create words with layered emotional impact. A word made entirely of "smooth, gentle" sounds will feel very different from one built from "sharp, aggressive" sounds.

## II. Monophthong Textures (7 Single Vowels)

### `a` — /a/ (central low)

| Field | Detail |
|:---|:---|
| **Texture** | Warm, open, neutral. The most "default" vowel — like a canvas. |
| **Emotion** | Calm, grounded, inclusive. No sharp edges. |
| **Tone type** | gentle, calm, light |
| **Suited for** | Base nouns (people, earth, water), everyday verbs, neutral particles. Good as a "filler" vowel in long words to space out harder sounds. |
| **Kilor example** | `amer` /ˈa.meɹ/ — "to love" — open and warm |

### `e` — /e/ (mid-high front)

| Field | Detail |
|:---|:---|
| **Texture** | Clear, bright, precise. Like a bell note — clean and forward. |
| **Emotion** | Alertness, clarity, gentle energy. |
| **Tone type** | bright, crisp, smooth |
| **Suited for** | Verbs of perception (see, hear, know), abstract nouns, words for speech and thought. Adds "intelligence" to a word. |
| **Kilor example** | `chel` /ˈtʃel/ — "to speak" — bright and forward |

### `i` — /i/ (high front)

| Field | Detail |
|:---|:---|
| **Texture** | Sharp, thin, piercing. The highest, most tense vowel — small and focused. |
| **Emotion** | Intensity, precision, nervous energy. |
| **Tone type** | sharp, bright, light |
| **Suited for** | Small things, fast actions, diminutives, particles for emphasis. Too much /i/ in one word can feel "squeaky." |
| **Kilor example** | `shili` /ʃi.li/ — "river" — the /i.i/ sequence evokes a narrow, swift stream |

### `o` — /ɔ/ (mid-low back, rounded)

| Field | Detail |
|:---|:---|
| **Texture** | Deep, heavy, resonant. Like a drum beat — weight and substance. |
| **Emotion** | Solemnity, gravity, stability. |
| **Tone type** | heavy, dark, calm |
| **Suited for** | Nouns for large physical objects (mountains, buildings), ritual words, funeral vocabulary, poetry end-rhymes. Grounds a word. |
| **Kilor example** | `blon` /ˈbˡɔn/ — "to collapse" — heavy and resonant |

### `u` — /u/ (high back, rounded)

| Field | Detail |
|:---|:---|
| **Texture** | Deep, resonant, hollow. Like wind through a cave — encompassing and dark. |
| **Emotion** | Mystery, depth, quiet power. |
| **Tone type** | dark, heavy, smooth |
| **Suited for** | Words for night, depth, water, inner experience. Excellent in coda position (word-final) to close a word with richness. |
| **Kilor example** | `fru` /ˈfɹu/ — "floral" — deep and smooth |

### `y` — /y/ (high front, rounded)

| Field | Detail |
|:---|:---|
| **Texture** | Exotic, delicate, almost bird-like. A compressed /i/ — tight and unusual. |
| **Emotion** | Strangeness, delicacy, tension. Feels "foreign" and refined. |
| **Tone type** | sharp, light, soft (paradoxically — sharp and soft at once) |
| **Suited for** | Rare, precious, or alien concepts. Magic words, poetry, terms of endearment, words for small delicate things. Use sparingly — only 11 words in DB. |
| **Kilor example** | `my` /my/ — a short, delicate root |

### `ae` — /æ/ (low front)

| Field | Detail |
|:---|:---|
| **Texture** | Bright, flat, slightly nasal. "Cat-like" — open and forward. |
| **Emotion** | Disgust (emotional register), rawness, directness. |
| **Tone type** | bright, sharp, aggressive (when intentional) |
| **Suited for** | Words for earthy, raw, or unpleasant things. The brown emotional particle. Also works for very direct, unpolished speech. |
| **Kilor example** | `famae` /fa.mae/ — "human being" (informal) — earthy and direct |

## III. Diphthong Textures (7 Diphthongs)

Diphthongs add **motion** — the glide from one vowel position to another creates a sense of movement or transformation within a single syllable.

### `ai` — /aɪ/ (low central → high front)

| Field | Detail |
|:---|:---|
| **Texture** | Rising, brightening. Opens wide then lifts — like dawn breaking. |
| **Emotion** | Hope, discovery, opening. |
| **Tone type** | bright, smooth, light |
| **Suited for** | Words for light, morning, discovery, ascension. The glide ends high — good for words that "rise." |
| **Kilor example** | `lai` /ˈlaɪ/ — the numeral 7 — bright and open |

### `au` — /aʊ/ (low central → high back)

| Field | Detail |
|:---|:---|
| **Texture** | Expansive, deepening. Opens wide then sinks — like a horizon stretching out. |
| **Emotion** | Wonder, vastness, melancholy. |
| **Tone type** | smooth, heavy, dark |
| **Suited for** | Words for sky, ocean, distance, time. The most "epic" diphthong — 35 words in DB, the most used. |
| **Kilor example** | `aug` /ˈaʊɡ/ — "to enter" — expansive and open |

### `ei` — /eɪ/ (mid-high front → high front)

| Field | Detail |
|:---|:---|
| **Texture** | Lifting, brightening, elegant. A subtle upward glide — refined. |
| **Emotion** | Grace, lightness, optimism. |
| **Tone type** | bright, smooth, crisp |
| **Suited for** | Verbs of movement (fly, rise, climb), adjectives for beauty, poetry. |
| **Kilor example** | `ei` /ˈeɪ/ — the conjunction "and" — light and connective |

### `eu` — /eʊ/ (mid-high front → high back)

| Field | Detail |
|:---|:---|
| **Texture** | Foreign, exotic, soft. Starts bright, ends muted — unusual and memorable. |
| **Emotion** | Strangeness, elegance, otherworldliness. |
| **Tone type** | soft, smooth, dark |
| **Suited for** | Rare, poetic, or "foreign" concepts. Used only 4 times in DB — treat as a spice, not a staple. Adds a European-language texture. |
| **Kilor example** | `meus` /ˈmeʊs/ — "of the sky" — soft, almost feline |

### `iu` — /i̯u/ (high front → high back)

| Field | Detail |
|:---|:---|
| **Texture** | Flowing, liquid. A pure vowel glide from /i/ to /u/ — like water pouring. |
| **Emotion** | Fluidity, smoothness, elegance. |
| **Tone type** | smooth, gentle, soft |
| **Suited for** | Words for water, flow, time, music. The "most beautiful" diphthong — smooth all the way through. |
| **Kilor example** | `auronius` /aʊ.ɹɔ.ni̯us/ — "sky-like" — flowing and graceful |

### `oi` — /ɔɪ/ (mid-low back → high front)

| Field | Detail |
|:---|:---|
| **Texture** | Playful, bouncing. Starts deep and rounded, jumps to bright — like a ball bouncing. |
| **Emotion** | Playfulness, surprise, energy. |
| **Tone type** | bright, crisp, sharp |
| **Suited for** | Children's words, exclamations, playful verbs, onomatopoeia. |
| **Kilor example** | `doi` /ˈdɔɪ/ — the numeral 12 — bouncy and bright |

### `ou` — /oʊ/ (mid-high back → high back)

| Field | Detail |
|:---|:---|
| **Texture** | Round, smooth, flowing. A gentle dark glide — like honey pouring. |
| **Emotion** | Warmth, richness, contentment. |
| **Tone type** | smooth, heavy, dark |
| **Suited for** | Words for food, comfort, home, night. Warm and enveloping. |
| **Kilor example** | `choum` /ˈtʃoʊm/ — "autumn" — warm and flowing |

## IV. Consonant Textures by Family

### A. Edge-Only Consonants (Word Edges)

#### `sh` — /ʃ/ (voiceless postalveolar fricative)

| Field | Detail |
|:---|:---|
| **Texture** | Soft, whispering, hushing. Rounded lips give it a gentle, breathy quality. |
| **Emotion** | Quiet, secrecy, gentleness. |
| **Tone type** | soft, smooth, gentle |
| **Suited for** | Words for quiet things, wind, sleep, secrets. Excellent at word start to soften the attack. |
| **Kilor example** | `shem` /ʃem/ — whisper-soft start |

#### `ch` — /tʃ/ (voiceless postalveolar affricate)

| Field | Detail |
|:---|:---|
| **Texture** | Crisp, punchy, energetic. A sharp attack that softens into a hush. |
| **Emotion** | Action, decisiveness, energy. |
| **Tone type** | sharp, crisp, aggressive (when desired) |
| **Suited for** | Action verbs, commands, words for striking or breaking. Adds rhythmic punch to a word. |
| **Kilor example** | `chap` /tʃap/ — short and punchy |

#### `th` — /θ/ (voiceless dental fricative)

| Field | Detail |
|:---|:---|
| **Texture** | Soft, breathy, slightly lisping. Like a sigh — the tongue barely touches the teeth. |
| **Emotion** | Softness, vulnerability, breathiness. |
| **Tone type** | soft, gentle, light |
| **Suited for** | Abstract nouns, words for breath/wind/spirit, gentle verbs. Adds European texture. |
| **Kilor example** | `tha` /θa/ — like a soft exhale |

### B. Start-Only Consonants — Lateral-Release Family (`kl`, `tl`, `bl`, `ml`)

These consonants all share a **lateral release** — air escapes over the sides of the tongue during the release, giving each a distinctive "spreading" sensation. They feel explosive and spacious at once.

#### `kl` — /kˡ/ (velar lateral release)

| Field | Detail |
|:---|:---|
| **Texture** | Explosive, spreading. The /k/ pops deep in the throat, then air fans out sideways. Like a sword leaving its sheath. |
| **Emotion** | Aggression, suddenness, power. |
| **Tone type** | aggressive, sharp, crisp |
| **Suited for** | Combat words, sudden actions, verbs for striking, breaking, or entering forcefully. |
| **Kilor example** | `klush` /kˡuʃ/ — explosive start, soft end |

#### `tl` — /tˡ/ (alveolar lateral release)

| Field | Detail |
|:---|:---|
| **Texture** | Crisp, brittle, spreading. A lighter, more forward version of /kˡ/ — like cracking thin ice. |
| **Emotion** | Precision, brittleness, quickness. |
| **Tone type** | sharp, crisp, light |
| **Suited for** | Words for small breaking sounds, precise actions, delicate but sharp movements. |
| **Kilor example** | `tlaur` /tˡaʊɹ/ — crisp + expansive |

#### `bl` — /bˡ/ (voiced bilabial lateral release)

| Field | Detail |
|:---|:---|
| **Texture** | Buzzing, spreading, thick. A voiced explosion that fans out — like a hive of bees disturbed at once. |
| **Emotion** | Weight, pressure, contained energy. |
| **Tone type** | heavy, aggressive (soft attack), dark |
| **Suited for** | Words for rumbling, pressure, weight, things building up to release. |
| **Kilor example** | `blon` /bˡɔn/ — heavy and buzzing |

#### `ml` — /mˡ/ (nasal lateral release)

| Field | Detail |
|:---|:---|
| **Texture** | Humming, spreading. A nasal hum that fans out sideways — like a long "mmmmm" that spills open. |
| **Emotion** | Contemplation, resonance, depth. |
| **Tone type** | soft, heavy, smooth |
| **Suited for** | Words for meditation, humming, deep thought, resonance. 0 words in DB — reserve for special concepts. |
| **Kilor example** | (none yet — conceptual) |

### C. Start-Only Consonants — Approximant-Release Family (`kr`, `br`, `gr`, `fr`, `pr`, `sr`)

These consonants all end in the English-style **r-sound /ɹ/** — a smooth, flowing approximant that gives each one a **European-language texture**. The r doesn't "tap" or "trill"; it **flows**, like a string instrument's sustain.

| **Emotion** | Determination, clarity, drive. |
| **Tone type** | crisp, smooth, bright |
| **Suited for** | Words for movement, creation, forceful but elegant actions. English "cry" texture. |
| **Kilor example** | (none yet — 0 words in DB) |

| **Emotion** | Warmth, strength, stability. |
| **Tone type** | smooth, heavy, bright |
| **Suited for** | Words for strength, protection, warmth. English "bright" texture. |
| **Kilor example** | (none yet — 0 words in DB) |

#### `gr` — /ɡɹ/ (voiced velar plosive + approximant r)

| Field | Detail |
|:---|:---|
| **Texture** | Deep attack, smooth sustain. A low rumble that flows forward. Like a double bass. |
| **Emotion** | Grandeur, depth, weight. |
| **Tone type** | heavy, smooth, dark |
| **Suited for** | Words for large things, deep sounds, earth, gravity. English "grand" texture. |

#### `pr` — /pɹ/ (voiceless bilabial plosive + approximant r)

| Field | Detail |
|:---|:---|
| **Texture** | Light pop, smooth sustain. The lightest of the plosive-r family. |
| **Emotion** | Pride, precision, forward motion. |
| **Tone type** | crisp, smooth, light |

### D. End-Only Consonants (Word-Final Coda)

End-only consonants close a word. They shape the **tail** of the word's texture — how it lands, how it resonates.

#### `ng` — /ŋ/ (velar nasal)

| Field | Detail |
|:---|:---|
| **Texture** | Resonant, humming, lingering. The sound continues through the nose — it doesn't "stop," it fades. Like a bell still ringing. |
| **Emotion** | Peace, finality, resonance. |
| **Tone type** | calm, heavy, smooth |
| **Suited for** | Words for endings, rest, completion. Excellent for poetry end-rhymes — the nasal hum carries across the pause. |
| **Kilor example** | `song` /sɔŋ/ — peaceful closure |

#### `x` — /x/ (voiceless velar/uvular fricative)

| Field | Detail |
|:---|:---|
| **Texture** | Rough, dry, scraping. Like a blade being sharpened — abrasive and definitive. |
| **Emotion** | Finality, harshness, starkness. |
| **Tone type** | aggressive, sharp, dark |
| **Suited for** | Words for cutting, ending, harsh things. The "hard stop" coda — use when a word needs to land with force. |
| **Kilor example** | `hax` /hax/ — dry and cutting |

#### `rk` — /ɹk/ (approximant r + velar plosive)

| Field | Detail |
|:---|:---|
| **Texture** | Flow into a hard stop. The /ɹ/ carries the sound forward, then the /k/ cuts it off sharply. Like a bow drawn across a string, then stopped. |
| **Emotion** | Tension, drama, finality with weight. |
| **Tone type** | heavy, dark, aggressive |
| **Suited for** | Words for dramatic endings, heavy objects, forceful closure. Currently 0 words — reserve for high-impact vocabulary. English "dark" texture. |
| **Kilor example** | (none yet — conceptual) |

## V. Design Principles for Word Creation

### A. Mixing Textures

A beautiful Kilor word balances contrasting textures. A word made entirely of aggressive consonants will feel jagged; one made entirely of soft sounds will feel vague.

| Good balance | Poor balance |
|:---|:---|
| `klush` — aggressive start (/kˡ/) + soft end (/ʃ/) | Hypothetical `kluklux` — all harsh, no soft |
| `auronius` — open (/aʊ/) + heavy (/ɔ/) + flowing (/i̯u/) + crisp (/s/) | Hypothetical `mumumu` — all soft, no definition |
| `shem` — soft start (/ʃ/) + clear vowel (/e/) + nasal stop (/m/) | — |

**Rule of thumb:** Aim for **one texture shift** per word — either start-hard-end-soft, or start-soft-end-hard. Three or more shifts in one word may feel chaotic.

### B. Vowel Brightness Control

Vowels can be ordered from **bright** (high front) to **dark** (low back):

```
bright ← i, y, e, ae, a, o, u → dark
```

| Word tone | Vowel strategy |
|:---|:---|
| Aggressive, sharp | Use high vowels (/i/, /y/), lateral-release consonants |
| Smooth, flowing | Use diphthongs (/aʊ/, /i̯u/, /oʊ/), approximant-release consonants |
| Heavy, solemn | Use back vowels (/ɔ/, /u/), end-only nasals (/ŋ/) |
| Light, playful | Use front vowels (/e/, /æ/), diphthong /ɔɪ/ |
| Soft, gentle | Edge-only /ʃ/ /θ/, approximant-release, front vowels |

### C. Managing the European-Texture Sounds

Some Kilor sounds carry a distinct "European language" texture — they evoke English, German, or Romance languages:

| Sound | European association |
|:---|:---|
| /ɹ/ (English r) | English, Dutch |
| /θ/ (th) | English, Greek, Icelandic |
| /y/ (ü) | German, French, Mandarin |
| /eʊ/ (eu) | Spanish, Italian, rare |
| /x/ | German, Scottish, Spanish |

For a word to feel **universal** or **Asian-accessible**, minimize these sounds. For a word to feel **deliberately European** or **exotic**, feature them prominently.

A word like `klush` (/kˡuʃ/) uses **zero** European-texture sounds — it could be from any language family. A word like `threugor` (/θɹeʊ.ɡɔɹ/) uses **four** European-texture sounds — it would feel strongly English/Germanic.

### D. Consonant Family Aesthetics Cheat Sheet

| If you want this feeling... | Use this family... | Example |
|:---|:---|:---|
| Explosive, aggressive, sudden | lateral-release (`kl`, `tl`, `bl`) | `klush` |
| Smooth, flowing, European | approximant-release (`kr`, `br`, `gr`, `fr`, `pr`, `sr`) | `gra`, `fru` |
| Soft, whispery, gentle | edge-only (`sh`, `th`) at word start | `shem` |
| Punchy, rhythmic, active | edge-only (`ch`) | `chap` |
| Resonant, peaceful, lingering | end-only (`ng`) | `song` |
| Harsh, definitive, final | end-only (`x`, `rk`) | `hax` |
